## Status labels

- **Canonical** — the source of truth. Other documents link to it instead of repeating it.
- **Current** — up to date with the canonical specification.
- **Draft** — being written; contains items marked TBD.
- **Translation** — follows the canonical English version; if they differ, English prevails.
- **Archived** — kept for history, no longer maintained.

Numbers marked **candidate** are expected to change once the balance harness exists (stage A).
